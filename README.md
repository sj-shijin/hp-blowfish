# hp-blowfish

ShiJin 的个人网站，使用 [Hugo](https://gohugo.io/) 与 [Blowfish](https://blowfish.page/) 主题，发布在 GitHub Pages。

站点地址：https://shijin.space/

## 本地预览

需要已安装 Hugo Extended（建议 0.162.0 或更高版本）。

```bash
git clone --recurse-submodules https://github.com/sj-shijin/hp-blowfish.git
cd hp-blowfish
hugo server
```

推送到 `main` 后，GitHub Actions 会自动构建并部署。
